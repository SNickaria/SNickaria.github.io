# Dr. Shiva NickAria - Personal Research Website

Static personal website for Dr. Shiva NickAria, Founder & AI Platform Architect at ARIA Therapeutics.

## Deployment

In repository Settings -> Pages, configure deployment from the main branch and the root directory. Verify the deployed website at https://snickaria.github.io/ before sharing it.

## Discovery follow-up

After successful deployment, verify ownership in Google Search Console, submit sitemap.xml, and inspect the homepage. A verification token must be provided by the site owner; none is included here. Search indexing and AI citations are not guaranteed.

## Content maintenance

Keep the visible biography and JSON-LD identity data consistent. Link congress study titles only to verified official abstract or poster pages when their URLs are available. Do not publish proprietary research or code without clearance. The spatial analysis code is planned for release upon manuscript acceptance; no other code-release commitment is made.
